## 1. 文档目的

为「体素风格的西秦会馆大门解构」提供：

1. 经核实的建筑形制数据（比例、层次、构件构成）；

## 2. 基本史实（来源：中文维基百科《西秦会馆》条目，2025-03-26 版）

### 2.1 身份与沿革

| 项目 | 内容 |
|---|---|
| 名称 | 西秦会馆（又名关帝庙，俗称陕西庙） |
| 地址 | 四川省自贡市自流井区解放路107号 |
| 坐标 | 29°21′06″N 104°46′07″E |
| 功能变迁 | 清代陕西盐商同乡会馆 → 1959 年起为自贡市盐业历史博物馆（中国唯一盐业历史博物馆） |
| 文保级别 | 1980-07-07 列入四川省第一批省级文保；1988-01-13 列入第三批全国重点文物保护单位（编号 3-76） |

### 2.2 修建时间线

```
雍正十年(1732)  "西秦大会"与龙峰井作坊主李光华签订买地契约
乾隆元年(1736)  动工 ──历时16年──> 竣工（耗资五万两白银）
道光七年(1827)  重修扩建（筹银四万余两，聘川南建筑师杨学三主持，
                历时两年），形成今日建筑风貌
```

> 注意：现存风貌是 **1827 年重修后的版本**。做"清代原构"还是"现状复原"，默认按现状（1827 版）。

### 2.3 规模与布局

- 占地约 3640 ㎡（另一说 4000 ㎡）；建筑面积约 3000~3100 ㎡。
- 平面矩形，**坐东南向西北**，四周以山墙、隔轩、廊屋等次要建筑环绕。
- **86 米中轴线**上由外至内依次为：
  `武圣宫大门 → 献技诸楼 → 大丈夫抱厅 → 福海楼 → 抱厅 → 参天阁 → 中殿 → 正殿`
- 轴线两侧由外至里：金镛阁、贲鼓阁 → 左右客廨 → 内院、神庖与内轩。
- 门厅内进为**天街**（约 798 ㎡ 平坝），由东西向的金镛阁、贲鼓阁与南北向的献技诸楼、大丈夫抱厅合围而成，四座建筑以连廊互通。

## 3. 大门本体：武圣宫大门 × 献技诸楼复合建筑 ★本次建模对象★

维基百科原文要点（关键！）：

> "建筑正门的武圣宫大门与献技诸楼构成了独立的复合型建筑。"
> - 武圣宫大门为**四柱七楼**牌坊式门，**面宽约 32 米**；
> - 其上为**四层重檐歇山式屋顶**，檐角成行，**由上至下依次加宽**；
> - 献技诸楼四层高，屋顶由两层歇山式屋顶组成，并在靠近正脊处加建**六角形盔顶**，其后两角**镶嵌在武圣宫大门歇山式屋顶中**，由此形成一个有 **24 个檐角**的大屋顶；
> - 复合建筑下由 **22 根石柱**和众多梁枋支撑；
> - 复合建筑内为四层：一层门厅，二层献技楼，三层大观楼，顶层福海楼。

### 3.1 这段话对建模的三点直接影响

1. **我们建模的不是一扇门，而是一组复合建筑**：临街面（正面）是四重檐的门楼牌坊；其背后（院内面）叠着献技诸楼的二层歇山 + 六角盔顶。两者屋面互相穿插咬合——这是西秦会馆大门最独特的结构特征，也是体素模型的"记忆点"。第一版可以先只做**临街立面 + 屋顶外轮廓**，盔顶作为 M4 里程碑加入。
2. **24 个檐角**意味着檐角起翘是数量化的：四重檐 × 正面两角 = 8 个，加上献技诸楼两层歇山与盔顶的角，合计 24。体素模型中每个檐角都要做出来，不能含糊成一整条水平檐口。
3. **22 根石柱**是底层支撑体系。底层（门厅层）柱应为石质（照片中可见底层柱为石造/包柱，上层为木柱），建模时底层柱用石材色板、上层用木/朱红色板，材质区分本身就是知识点。

### 3.2 立面分层（对照照片归纳，比例近似）

以正立面中央门楼为准，自下而上：

```
[y≈0    ] 石台基 + 中央台阶 + 栏杆
[y≈0.9m ] 台基面：石狮一对（含须弥座）分列踏步两侧
[门堂层 ] 底层：22根石柱中的前檐柱列；中央开间为黑漆大门（双扇板门），
          门堂两侧为白灰墙 + 深色木门/格栅（次间、稍间）
[y≈6m   ] 第一重檐：跨度最大（覆盖中央门楼并搭接两翼屋面），
          檐下为如意斗栱密排带（远观呈"金点黑底"横带）
[二 层  ] 黑漆墙身：中央大匾（黑漆描金"自贡市盐业历史博物馆"，郭沫若题*）
          两侧黑漆团窠花板（金雕圆形图案）+ 朱红/黑漆柱
[y≈10m  ] 第二重檐：跨度收窄，檐角高翘
[三 层  ] 黑漆墙身：中央木格窗（直棂/步步锦格心*），两侧小团窠花板
[y≈13m  ] 第三重檐：再收窄
[顶 层  ] 黑漆墙身：一块大团窠花板居中
[y≈16m+ ] 第四重檐（最小）→ 歇山正脊 → 灰塑卷草脊饰 + 宝顶
```

\* 匾额题字者与格心样式见 §7 待核实清单。

### 3.3 平面上的宽度节奏（估算）

```
|—两翼廊庑—|—次间—|———中央门楼———|—次间—|—两翼廊庑—|
   ~6m        ~5m       ~12m         ~5m       ~6m     ≈ 总面宽 32m
```

- 中央门楼最宽最高，四重檐全部集中在这一跨；
- 次间单檐（或平顶披檐），高度约到中央门楼第二重檐之下；
- 两翼廊庑最低，白墙 + 木格窗，单坡/单檐。
- **体素化含义**：立面是"中间高、两侧低"的三级天际线，每级交界处都有明显的檐角起翘与屋面高差，这是轮廓辨识度的来源。

## 5. 雕刻与装饰体系（体素化对象清单）

### 5.1 木雕（黑漆描金系）

| 构件 | 位置 | 特征 | 体素处理策略 |
|---|---|---|---|
| 团窠花板 | 二、三、四层墙身 | 黑漆底 + 圆形描金团窠（内圈夔龙/卷草） | 主模型：金圆环 + 中心花块（2~3 层浮雕深度）；特写件单独高模 |
| 戏文人物看板 | 献技诸楼檐下（背面/院内视角） | 多色：金人 + 石青地 + 朱红点缀 + 回纹金框，深浮雕 | 主模型简化为色带；M4 出 1 块特写样板 |
| 撑拱（斜撑） | 檐柱上部 | 金色龙形/仙鹤形镂雕 | 体素龙形剪影，3~5 格厚，头部朝外 |
| 如意斗栱带 | 各重檐下 | 密排小斗，金色 | 程序化：每 2 格一个 2×2×2 金色斗块 + 黑色横栱 |
| 木格窗 | 三层墙身中央 | 直棂/格心窗，深色 | 1 格深的格栅纹理（程序化条纹） |

### 5.2 石雕

| 构件 | 特征 | 体素处理 |
|---|---|---|
| 石狮一对 | 卷毛、张口、胸前佩铃（观察），灰色砂岩，含须弥座 | 单独分件建模（全模型最重要的圆雕件），主模型约 10×12×14 格/只，特写件 1vx=0.02m 高模 |
| 御路陛石 | 院内，圆形龙凤浮雕 | 可选扩展件（M5+） |
| 石栏杆/望柱 | 台基边缘 | 程序化重复单元 |

### 5.3 灰塑（屋脊）

- 正脊：浅白灰色连续卷草/人物题材，脊端鸱吻状收头，中央宝顶；
- 角脊：端部走兽小团块；
- 体素化：脊部用 1~2 格凸起的浅色带 + 端部 2~3 格团块表达，不追求纹样可读性。

### 5.4 瓦作与杂项

- 青灰筒瓦（观察：屋面有明显筒瓦垄），檐口瓦当一排（可用 1 格交替色表现）；
- 檐角风铃：1×1×2 小块悬挑，数量 ≤8（每角一枚）。

## 6. 色彩体系（从照片取样估计，建模前可微调）

## 7. 待核实清单（进入开发前需确认项）

| # | 事项 | 当前依据 | 风险/影响 |
|---|---|---|---|
| 1 | 大门通高的准确数据（文献未见精确值，估 16~17m） | 照片比例推算 | 影响整体网格预算 ±10% |
| 2 | "四柱七楼"的确切读法（四柱易解，七楼的分位需对照正射照片） | 维基文字 + 全景照 | 影响 7 个屋顶单元的分件划分 |
| 3 | 匾额题字者（通行说法为郭沫若 1959 年题写馆名，维基未载） | 常识 | 仅影响文案，不影响建模 |
| 4 | 瓦作类型（筒瓦 vs 合瓦）与瓦当纹样 | 照片观察倾向筒瓦 | 影响檐口 1~2 种色块节奏 |
| 5 | 各重檐的准确开间数与柱位 | 照片部分遮挡 | 影响柱网生成参数 |
| 6 | 戏文看板的题材名目（具体剧目） | 博物馆文献未查到 | 不影响建模，仅影响导览文案措辞 |
| 7 | 石狮数目（正面对：一对大型；是否另有小型） | 全景照可见 ≥2 大 + 翼端小 | 影响台基层分件数量 |

> 结论：以上均不阻塞开发启动，按"照片优先、标注存疑"原则推进；如后续获得实测数据或官方测绘图，替换对应参数即可。
