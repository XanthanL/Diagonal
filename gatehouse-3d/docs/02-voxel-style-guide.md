# 体素风格指南 —— 西秦会馆大门的体素化转译

> 前置阅读：《01-research.md》
> 本文档回答一个问题：**如何把一座清代川南牌楼门，翻译成体素语言而不失其神。**
> 样例图片见 `docs/samples/`（由 `tools/gen-samples.ps1` 程序生成，可复现、可改参）。

---

## 1. 三条风格总纲

1. **剪影优先（Silhouette First）**
   观众在 3~10 米视距上读到的是轮廓：四级天际线 + 24 个翘角 + 中央塔楼收分。先把轮廓做对，再谈纹样。任何时刻眯眼看模型，"这是一座高翘檐角的牌楼门"必须成立。
2. **色块克制（≤20 色）**
   体素风的力量来自有限的调色板。黑漆/描金/石青/朱红/白灰/砂岩/青瓦七族，每族明暗两档，全模型 ≤20 色。禁止渐变、禁止贴图。
3. **细节分层（3×LOD）**
   - **LOD-A 主模型**（1 vx = 0.2 m）：完整建筑，雕刻只到"浮雕深度 + 色块"级别；
   - **LOD-B 特写件**（1 vx = 0.02~0.05 m）：单块花板 / 石狮 / 匾额，可读出纹样骨架；
   - **LOD-C 氛围件**：斗栱带、瓦当、风铃等程序化重复单元，只求节奏不求个体。

## 2. 尺度与网格预算

| 参数 | 取值 | 说明 |
|---|---|---|
| 主比例 | **1 voxel = 0.2 m** | 与文献尺寸直接换算 |
| 主模型网格 | 约 160 × 120 × 44 (W×H×D) | 面宽 32m → 160；通高按 elevation-guide 口径 ≈23.6m → 118 格（含宝顶；2026-08-22 用户裁决"就高"，原 17~20m 估算作废）；进深估 8m+出檐 → 44 |
| 实际填充 | < 15 万实心格 | 屋面为壳（2~3 格厚），墙体镂空门窗 |
| 特写件网格 | ≤ 64³ / 件 | 花板、石狮、匾额各一件 |
| 渲染目标 | 合并后单 Mesh ≤ 30 万三角形 | 见《03-dev-plan.md》§4 可见面剔除 |

坐标系约定：**X 向右（面宽），Y 向上，Z 向南（临街方向朝 −Z 观察）**；原点在台基前缘中点地面。

## 4. 屋顶的体素化规则 ★核心工艺★

### 4.1 举折阶梯（坡面）

清式举折是"逐级变陡的下凹曲线"，体素化为**阶梯步距递减**：

- 下段（檐坡缓）：每上升 2 格，内收 3 格；
- 中段：每上升 2 格，内收 2 格；
- 上段（近脊陡）：每上升 2 格，内收 1 格；
- 到正脊：留 2 格宽水平脊带，脊上再加灰塑层。

屋面壳厚 2 格：外层瓦色（青灰两档交替形成瓦垄感），内层深色（椽望），檐口端头翻 1 格白色（滴水/瓦当线）。

### 4.2 檐角起翘（24 个角的来源）

**铁律（2026-08-29 用户复核，纠正既往"板状长尾/挂风铃"的错误做法）**：房檐末端必须是**尖角**——一条符合力学与美学的弧线，自粗到细、由下而上挑起，末梢收尖如**牛角**（先平缓、越外越翘、终成一点）。绝不可做成等深平铺的板状尾，也不挂风铃（实拍无此物）。

正面每重檐左右各一角，实现见 `voxel/ops.js` eaveBand/eaveTip：

- **深度收拢**：角部 z 向出挑随外扩以幂曲线 `(1-u)^1.15` 向檐带中轴收分，末段仅 3→2→1 格宽；
- **抬升弧线**：顶缘沿上扬弧逐段抬高，末梢以单格金尖成牛角点（先缓后陡）；
- **搭接不断**：相邻段共享整行体素，保 6-连通接地（#11 断言守护）；
- 上层檐角比下层略短，避免四层等长呆板。

### 4.3 歇山与脊饰

- 每重檐顶部做微型歇山：长度方向保留 4~6 格平脊，前后坡交汇处内收 1 格形成山花面（用黑漆色区分瓦面）；
- 最顶层（第四重）歇山最大，正脊上叠灰塑：1~2 格高的白灰色连续带 + 两端鸱吻团块（3×3×3 内收成阶梯状）+ 中央宝顶（2×2×4 小塔状阶梯块）。

### 4.4 样例图对照

见 `samples/roof-profile-guide.png`：
左图为坡面阶梯（标注三段步距），右图为角部起翘的对角阶梯（标注步数）。建模时严格按图执行，两个屋面相接处的"咬合缝"统一内退 1 格，防止 z-fighting。

## 5. 斗栱带 · 彩画带 · 瓦当（LOD-C 程序化单元）

| 单元 | 规则 |
|---|---|
| 如意斗栱带 | 檐下整圈：沿 X 每 3 格一个金色 2×2×2 斗块，斗间黑色 1 格高垫栱；上下各留 1 格黑漆底带 |
| 彩画横带 | 石青地 3 格高 + 白色宝相花点阵（每 6 格一朵 2×2 白块 + 金芯 1 格）+ 中部赭金开光（宽 10~14 格） |
| 瓦当线 | 檐口外缘 1 格高：青灰亮/暗交替（周期 2 格） |
| 风铃 | 每个翘角尖下 1 枚 |

以上全部由代码参数化生成（`builder.js` 的 `patternBand()` 族函数），不手工摆放。

## 6. 雕刻件的体素化策略

### 6.1 团窠花板（主模型 LOD-A）

黑漆底板（凸出墙面 2 格）→ 金色圆环（半径 5~7 格的八边形近似圆）→ 环内深底 → 中心金色花团（十字/菱形 3×3~5×5）。远看即"黑底金团"。样例：`samples/carving-roundel-sample.png`。

### 6.2 戏文看板特写（LOD-B 样板）

取 `fredriksen-c.jpg` 的主画面舟船人物场景做一块 64×40 特写板：

1. 先铺石青地 + 金回纹边框（边框宽 3 格，回纹用 90° 折线单元）；
2. 人物 = 金色剪影块（头 2×2、身 3×4、持械臂 1×2），一景放 5~7 人，高低错落；
3. 舟船 = 金褐色弧形阶梯底座；水波 = 浅青色横向波条（1 格高，错位重复）；
4. 树石 = 金绿团块压在画面上部两角。
   判定标准：截图缩到 25% 后仍能读出"金人蓝水的戏曲场景"。

### 6.3 石狮（LOD-B，唯一的大圆雕）

14×12×16 格/只，分六段搭建：须弥座（3 格高，上枋-束腰-下枋）→ 四肢蹲坐块 → 躯干（前倾 2 格）→ 卷毛头（头部整体外扩 1 格，表面用 1 格凸点阵列表现卷毛，共 8~10 个凸点）→ 张口与下颌（挖 2 格槽）→ 尾巴贴背 S 形 3 段。左右镜像，**头朝向模型中心**。

### 6.4 匾额

主模型：黑漆匾框 + 金字行（不做真字，用 2 格高的金色短划模拟笔画节奏，共 9 字位）；特写件可选做"自贡市盐业历史博物馆"九字的 16×16 点阵体素字（M5 可选任务）。

## 8. 搭建顺序清单（自下而上、先骨后皮）

```
[1] 台基 + 台阶 + 石栏杆基线          （terrace）
[2] 柱网定位：底层前檐柱列            （columns，先立 8~10 根可见柱校比例）
[3] 门堂：大门扇 + 白灰墙 + 次间格栅   （wings 下半）
[4] 石狮 ×2                           （lions）
[5] 第一重檐：斗栱带 → 檐口 → 坡面     （eave1）
[6] 二层墙身：匾额 + 团窠             （plaque）
[7] 第二重檐 → 三层墙身(木格窗) → 第三重檐
[8] 顶层墙身 → 第四重檐 → 歇山 + 灰塑脊 + 宝顶 （eaves-upper 完成）
[9] 全部檐角起翘修型 + 风铃           （逐角核对，共 8 个正面角）
[10] 次间/两翼屋面收尾                （wings 完成）
[11] 整体眯眼测试：轮廓 vs salt-museum-2009.jpg 对照
[12] (M4) 盔顶与献技诸楼背面屋面咬合
[13] 特写件三件套：团窠板 / 戏文看板 / 石狮高模 （carving）
```

每完成一步跑一次"截图比对照片"再进入下一步。

## 9. 工程约束（给 builder.js 的硬性要求）

1. 体素数据 = `Map<key,string>`（key 为 `"x,y,z"`，value 为色号）；同格后写覆盖先写；
2. 输出几何时做**可见面剔除**（六邻域检测），并按 X 连续同色段做 run-merging 合并矩形面；
3. 每个 Part 单独 build 再合并，保留 `partId` 写入顶点 attribute；
4. 全部生成函数纯函数化（入参为参数对象），保证同一份参数必然产出同一模型（便于 selftest 断言顶点数/包围盒）。
