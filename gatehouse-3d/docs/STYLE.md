# 门楼 · 风格方向（唯一留存的设计文档）

> 本文只记**风格判据**，不记场景数据。旧场景的一切尺寸、布局、文案已作废并删除，
> 新版体素页面只对着这份文件从 0 重做。以后每轮改稿，先回到这里对判据，再动代码。

## 〇、立场

- 架空创作：一座无名、无官署归属的门楼，立于青山绿水之间，**赖以拄其间**。
  不指涉、不还原、不影射任何真实建筑；措辞与命名一律朴素，回归事物本身（门楼、水、山、桥、树）。
- 画面读作**一张纸上的山水**，不是一张实景照片。暖纸底是空，体素是墨，雾是留白。

## 一、氛围基线（工程侧固定，不再反复调）

| 项 | 取值 |
| --- | --- |
| 清屏色 / 雾色 | `#FAFAF8`（对角线暖纸底） |
| 雾 | `THREE.Fog(BG, 50, 170)` —— 近实远虚，地平线由雾收边 |
| 色调映射 | `ACESFilmicToneMapping`，exposure `1.05` |
| 材质 | `MeshLambertMaterial` + 顶点色，无阴影、无贴图、无后处理 |
| 灯光 | 半球光（白→`#d8d2c4`，0.95）+ 暖白主光（`#fff4e0`，1.05）自右上 |
| 比例 | `1 vx = 0.2 m` |

远景不做“画出来”的处理，交给雾淡出。**能被雾吃掉的细节，就不要画。**

## 二、构图铁律

1. **大开面优先**。画面由少数几个大色块构成：一片地、一湾水、一座门、几道山。
   任何元素在默认相机距离（≈50 m）外必须读得出轮廓，读不出就删。
2. **一个密集体 + 若干开敞面**。门楼是唯一的垂直密集体，其余全部让位：
   水在前、山在后、地横陈其间。切忌处处都是主体。
3. **横向长条是基本笔触**。体素沿 X 做 run 合并，横向长条最省三角形、也最像中国画的面性笔触；
   竖向靠"层层收分"堆出，不靠单点凸起。
4. **对称但不板滞**。中轴对称给庄重，破板滞只允许一处不对称（桥偏一侧、水偏一侧、山偏一侧）。
5. **元素种类 ≤ 6**。当前 5 种：地坪 / 水 / 桥 / 门楼 / 远山。想加第 6 种，先删掉一种。

## 三、色板用法（23 色，`js/voxel/palette.js` 单一来源）

- 建筑：瓦（暗垄/亮垄）、黑漆（主体/受光）、金（主体/高光）、朱红（柱/受光）、白灰（墙/暗）、
  砂岩（亮/暗）、栗木（格栅/受光）、椽望暗层、灰塑·亮。
- 自然：苔绿、松绿、黛绿、岩影 / 碧水、深潭 / 灵光。
- **明度分层是唯一的空间线索**：近景用满色域，中景压到 2 阶，远景只留 1 阶并靠雾提亮。
- 水只用两阶（`碧水` 面 + `深潭` 边）；墨线只描远岸一格，近岸直接接纸，**不做闭合边框**。
- 山是两道纸幕：近幕 `黛绿` 脚 → `松绿`，远幕 `松绿` 脚 → `岩影`；色只按高度两分，
  越远越浅，峰顶就是浅色，不戴"帽子"。
- `金` + `灵光` 是画面的高光预算，合计占比 < 1%，只出现在翘角末梢、匾框、脊心。
- 表外色名一律 `throw`；色名增删与本文同步。

## 四、翘角语汇（本作的灵魂，不可改动）

自檐带角端向外 `N` 段挑出（下层 `N=4`，逐层递减到 `N=2`）：

- 轨迹 `y = baseY + round(0.25 k²)` —— 先缓后陡，收在上扬。
- 深度 `3 → 2 → 1` 递减成尖；每段高 3 格且与左邻共享整行，保证 6-连通接地。
- 末段 `金·主体`，顶端一枚 `灵光` 冠尖；金只贴末段——多段金身读作金梯子。
- 下层角长、上层角短，总高不破网格上界。

**反面**：板状尾、平伸不出挑、末端截面不变尖、角尖比檐还粗 —— 出现即判不合格。

## 五、体素纪律

- 只用轴对齐长方体堆叠；`ops.*` 纯追加、可链式、同输入两次构建逐字节一致。
- 全部尺寸取自 `js/spec.js`（单一来源），生成器内不得写魔数。
- 跨 Part 零体素重叠（同格 z-fighting 直接判失败）；装饰层需要外凸就明确留出层位。
- 无悬空体素：6-连通必须接地。
- 预算：三角形 ≤ 340k（含山水），体素数尽量小——大片平铺用**单层**体素长条，不堆厚度。
- `?selftest` 常驻，全绿才算交付。

## 六、页面与载入

- 静态子项目，无构建步骤；`docs/tools/serve.mjs` 本地预览。
- 载入用共享纸面揭幕（`shared/viewer/loader.css` 的 `pt-veil`）：揭幕停留 ≥1 s 后**移除节点**，

## 七、反例清单（历史上真实翻车过的样子）

- 密集小构件：满排斗栱金点、四瓣团窠花板、成列回纹钩 —— 远看是噪点，不是细部。
- 白色 slab 堆叠成"宝顶"：一层层等高白方块 = 一摞纸盒。脊与顶要么一条线收掉，要么一个尖收掉。
- 黑色圆锥当山、顶戴灰色烟囱帽：读作一排松树，不是石峰。
- 用矩形边框当水岸泡沫：像贴了胶带。
- 散点乔木密密麻麻：树要么三五棵成组有主次，要么一棵不种。
- 把参考图、真实建筑名、进度任务表再塞回仓库：已清理，不再回来。
- 几段板叠当拱：桥读作塔阶。拱背必须逐列插值、坡率 ≤1/10，1 格台阶才读作弧。
- 全宽楔形当水面：读作撕开的纸。水是一湾，两岸收拢成圆头，墨线只描远岸。
- 桥面/水面与纸面只差 1 cm：浅视角下深度精度不够，地面从桥面透出来。共面的大平面之间要留 ≥0.2 m。
- 檐下贴一道饱和横带：读作胶带。白墙直接接暗檐，色相越少越安静。
- 正脊平台过大：屋面退化成一块灰平板。平台只比上一重墙身大一圈。
- 归一化周距在角端饱和：檐口出现 4 格悬崖。等 r 线必须是一圈相似矩形（取 min 不取 max）。
