# 门楼 · The Gatehouse —— 魔幻绿水青山 · 设计设定

> 本作品是**对角线档案中的架空创作**：一座无名义、无官署归属的门楼，立于青山绿水之间，
> 赖以拄其间。不指涉、不还原任何真实建筑；早期绑定的真实建筑研究与参考照片已全部删除，
> 现由想象驱动重建。进度与任务表机制随之废止，本文件是唯一设计说明。

## 一、造型母题

- **门楼主体**：四重檐复合门楼，黑漆为骨、描金点睛、朱红立柱、白灰墙皮（皮-腔-皮壳式砌置，
  三排柱：前廊 / 金柱 / 后檐，柱头枋分层）。中轴对称，`x∈[0,159]`，通高 118 格（`1 vx = 0.2 m`）。
- **魔幻长牛角翘角**（本作的灵魂）：每重檐两端各一记长翘角，自檐角向外 4~10 段挑出，
  坡度先缓后陡（`y = baseY + ⌊0.12k²⌉`），深度 3→2→1 收尖，末两格金身、顶端一枚**灵光**冠尖——
  如牛角般夸张上扬。下层角长、上层角短，总高不破 118 格。
- **匾留白**：一层大匾嵌描金框而匾文不题（架空之物无名可题）。

## 二、绿水青山（`parts/terrain.js` + `spec` 的 ENV/RIVER/BRIDGE/MOUNT/TREES）

- **地坪**：苔绿为面、岩影为骨；台基·踏步领地（`CARVE`）让位给建筑。
- **绕门碧水**：主河绕门楼左前、末端南折，另引一支汊；深潭为底、碧水为面、浪花点缀成纹；一架石梁桥跨水通渡。
- **层叠青山**：阶梯台地式山形（黛绿体·松绿/苔绿台面·高巅云雾为帽），横脊连峰成案；
  门后与两岸立数座**桂林式锥状石峰**（`KARST`：逐层向心收分成尖、顶覆云雾，最高 60 格），营造魔幻纵深感。
- **点状乔木**：树干栗木、树冠黛绿/松绿叠团、青翠为顶，散落于地坪。

## 三、色板（30 色单一来源，`js/voxel/palette.js`）

20 建筑色（瓦/黑漆/金/石青/朱红/白灰/砂岩/栗木/木雕/水波/灰塑）+ 10 自然灵光色
（苔绿·松绿·黛绿·青翠·岩影 / 碧水·深潭·浪花·云雾 / 灵光）。任何色名增删须与 DESIGN 同步，越表即 `throw`。

## 四、工程与纪律

- 静态子项目，无构建步骤，复用体素引擎（`voxel/{palette,builder,ops}.js`）；`?selftest` 钩子常驻。
- **确定性**：纯函数、同输入两次构建逐字节一致。
- **断言**（`js/selftest.js`，15 项）：builder 单元 + 几何全局——总包围盒（建筑本体，排除 terrain）、
  无悬空体素（6-连通接地）、四重檐宽度递减、跨 Part 无体素重叠、三角形 ≤340k（含山水）。
- 坐标系：`x∈[0,160)` 面宽、`y` 向上、`z∈[0,44)` 进深（+z 为正面）；镜像轴 `x→159-x`。
- 本地预览：`node docs/tools/serve.mjs 8123` → `http://localhost:8123/gatehouse-3d/`。
