## Users
Visitors to a contemporary art institution's digital archive — artists, curators, researchers, and a general public interested in media art, archives, and material culture. They browse curated "documents", "atlas" field records, and experimental "lab" demos. Context: desktop + mobile, gallery/museum-adjacent, bilingual (中文 / English).

## Brand Personality
Restrained, editorial, archival, material. Three words: **克制 (restrained) · 文献感 (archival) · 物质性 (material)**.
The interface should feel like a quiet, well-printed catalogue — confident minimalism, not decorative. Emotional goal: calm authority + curiosity.

## Aesthetic Direction
- **Primary theme**: light / warm-paper. Page background is warm paper `#FAFAF8`; ink `#1A1A1A`; brand red `#B33A2A` (暗朱, an iron-oxide red — NOT pure `#FF0000`) used ONLY as accent/structural signal (eyebrows, thin rules, hover).
- **Dark surface** `#0c0c0e` reserved for immersive/interactive pieces (the salt-particle simulation, archive "dark room" moments) — used sparingly, never as a default section background.
- **No full-screen black curtain** — not even for page transitions. The 2026-08-29 pass retired the dark five-column curtain precisely because a dark block reads as heavy decoration; transitions now move paper over paper.
- **Motif**: the diagonal slash (`.diagonal-line`, hero skew). Metadata uses a monospace "archive-text" label style (uppercase, wide tracking) — this is the signature, not a generic caption.
- **Anti-references**: generic AI card grids, gradient text, glassmorphism, neon/glow accents, hero-metric dashboards, pure-black-on-pure-white.
- **No pure black/white**: neutrals are tinted; use `black/10..60` opacity or `foreground`/`diagonal.warmGray` tokens.

## Typography
- Display/headings: Newsreader (Latin) + Noto Serif SC (CJK) — serif, used large and tight (`tracking-tighter`, `leading-none`).
- Body: Inter. Metadata/labels: JetBrains Mono / `archive-text` (mono, uppercase, wide tracking).
- **`/about` is the layout benchmark** (user, 2026-08-29). Section headers speak its language: a hairline top rule (`border-t border-black/10 pt-8`) + a small mono index label (`archive-text text-[10px] opacity-50`, letter-spacing ~0.3em) + a mid-size serif title at `font-bold` uppercase — no italic display.
- **Loaded serif weights are 400 / 500 / 700 only** (`layout.tsx`). `font-bold` is the heaviest real weight; anything above (`font-black`) triggers synthetic/faux bold with fuzzy edges — reserve it for the hero wordmark where the size forgives it.
- **Enterable entry titles stay at serif normal weight**: hierarchy comes from size, serif face and whitespace, not weight.
- Index rows: mono code column | serif title | secondary metadata as serif italic (people) + `archive-text` (types/locations). Row separators are `border-black/5` hairlines.
- **Red is rationed, and always structural**: on the homepage it marks the hero `PROJECT STATUS` rule, the primary `LOAD FULL INDEX+` CTA (red outline → solid red on hover; the one loud button on the page, deliberately), and the Atlas intro's flowing progress line. The mobile drawer carries an edge tick plus a red index on the current page. Everything else is ink.

## Motion
- Transform/opacity only. Easing: `--ease-out: cubic-bezier(0.23,1,0.32,1)` (Tailwind `ease-out-strong`). UI durations ≤300ms.
- **Page transition = 斜切纸面翻页** (`PageTransition.tsx` + `.pt-*` in globals.css): a `skewX(-12deg)` panel **in the page's own colour** (`var(--background)` — the user explicitly rejected a tinted sheet) sweeps left→right, led by a 2px diagonal hairline carrying a single red tick; the route swaps under the paper; the carriage keeps the same direction to uncover the new page, which rises in with `pageEnter`. Cover 460ms / hold 140ms / reveal 600ms, all on `--ease-wipe: cubic-bezier(0.62,0,0.3,1)` — a wipe must stay near-constant-speed or it reads as a flash-cut. Direction is continuous; nothing reverses. ⚠️ Because the sheet is the same colour as the page, the edge cues *are* the transition: a 60px/18px spread shadow plus that 2px rule. Never thin them out.
- The oversized panel's horizontal bleed is `calc(12vw + 11vh)`: the `vh` term is what keeps the skewed corners covering on tall/narrow screens. Derive lead lines and travel distance from that variable rather than hard-coding vw numbers.
- **The first-load veil must never be able to trap the page — three independent outs, keep all three:** (1) the intro reveal is driven by `setTimeout`, *never* `requestAnimationFrame` — rAF is fully suspended in background/occluded tabs, which left the veil up until a manual reload (real bug report); (2) a CSS-only `ptIntroLift` animation lifts `pt-intro` on its own after 2.6s, so a hung or errored bundle still uncovers; (3) `<noscript>` hides the overlay entirely.
- While the veil is up it shows a loading indicator (hairline track + travelling red segment + `加载中`), pure CSS so it animates before hydration. That is why the stale-route force-reveal waits 2.6s instead of 1s: uncovering early re-exposes the old page and then hard-swaps, which reads worse than holding.
- Hover feedback gated via `future.hoverOnlyWhenSupported` (no stuck hover on touch).
- **Mobile nav = narrow hanging scroll** (`#mobile-nav-drawer`, `.nav-drawer*` in globals.css): `w-[64vw] max-w-[17rem]`, page colour, anchored top-right under the hamburger. It unrolls **top→bottom via `clip-path: inset()`** and rolls back the same way — never `height` (layout thrash) and never `scaleY` (squishes the text mid-animation). `--bar-h` keeps the unroll emerging from under the header; items stagger downward with `--i` (delay only on the open state, so closing doesn't queue in reverse); left edge = hairline + red tick. Closed state uses a delayed `visibility:hidden` so off-screen links leave the tab order; body scroll locks and Esc closes while open.
- **Language switch lives in the top bar on every breakpoint** (mobile: left of the hamburger), never inside the drawer — the user asked for it to be reachable without expanding anything.
- **Overlay z-order contract**: page-level sticky bars (mobile section dock, nav) stay at `z-[60]`; scrim `z-[70]` < drawer `z-[75]` < header `z-[80]` < page transition `z-[90]`. The scrim/drawer must be siblings of `<header>`, never children — `header` is `fixed` + z-index, so it forms its own stacking context and an inner scrim would paint over the header's own wordmark.
- `prefers-reduced-motion` respected (framer-motion `MotionConfig reducedMotion="user"` + CSS media query). Reduced-motion users get no wipe at all: `navigate()` pushes directly and the intro beat collapses to `idle`; the drawer opens/closes instantly.
- Interaction primitives: `.press` (buttons, scale .97 on :active), `.press-card` (cards, hover lift + :active scale .99).

## Design Principles (guide all work)
1. Paper-first light theme; dark only for immersive demos.
2. Red is a structural accent, never decoration-for-its-own-sake.
3. `archive-text` mono labels carry all metadata — consistent and distinctive.
4. Motion is transform/opacity + reduced-motion; never animate layout (width/height/top/left).
5. Restraint over flourish — distinctive by intention, never generic AI aesthetics.

## Known tokens (Tailwind)
- `bg-background` = `var(--background)` = #FAFAF8
- `bg-diagonal-warmGray` = #FAFAF8 (card/cover surface)
- `text-foreground` / `bg-diagonal-surface`(#0c0c0e) / `text-diagonal-red` / `border-diagonal-red`
- CSS vars in `globals.css` `:root` for non-Tailwind rules: `--diagonal-red` (#B33A2A), `--ease-wipe` (constant-speed wipe curve), `--ease-out` / `--ease-in-out` / `--ease-drawer` (drawer now unrolls on `--ease-wipe`; `--ease-drawer` currently has no consumer)
- ⚠️ Do NOT use `text-ink-*` — `ink` is not a defined color and is a no-op class.
- ⚠️ Prefer the tokens above over hard-coded `#FAFAF8` / `#0c0c0e` / `#1A1A1A` / `#B33A2A`.
- ⚠️ Tailwind's `diagonal.red` intentionally keeps the literal hex (not `var(--diagonal-red)`) — a `var()` color would break `/alpha` modifiers like `border-diagonal-red/40`.
